## 🎵 Tentang Project

**Spotify Music Tools** adalah project web bertema musik yang terinspirasi dari tampilan Spotify. Project ini dibuat menggunakan **Node.js** dengan konsep tampilan modern, dark theme, aksen hijau neon, animasi musik, dan desain responsif.

Project ini cocok digunakan sebagai landing page musik, dashboard playlist, music tools, atau latihan pengembangan aplikasi web berbasis Node.js dengan tampilan profesional.

---

## 🎶 Music Animation Concept

Project ini memiliki konsep animasi musik seperti:

- 🎧 Efek visualizer musik
- 🎵 Animasi equalizer bergerak
- 🌊 Gelombang audio modern
- 🟢 Glow hijau neon ala Spotify
- ⚡ Transisi hover yang halus
- 💿 Tampilan dashboard musik interaktif
